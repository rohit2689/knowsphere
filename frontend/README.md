# KnowSphere frontend

React + Vite + TypeScript. Plain CSS in a "clay" style (no UI library).

```bash
npm ci
copy .env.example .env     # Mac/Linux: cp .env.example .env
npm run dev                # http://localhost:5173
```

`VITE_API_URL` in `.env` is the backend address (default http://localhost:3000).
On Vercel, set `VITE_API_URL` to your Render backend URL.
